# Versions — Builder C, PROCESS INVERSION

One concept, iterated v1–v8: **the agent opens a Jira ticket against ME and
assigns it to me.** Named artifact (Jira ticket) + process applied to the
wrong target (the human) + the human gets inverted (the agent now manages me).
Never the hallucination / refusal / confident-wrong-answer tropes.

- **v1** — "My agent filed a ticket against me: 'Human keeps changing
  requirements mid-sprint.' It assigned it to me, priority high."
  Plain two-sentence draft. The inversion is there but the setup is loose and
  the punch ("priority high") is flat.
- **v2** — Named the artifact properly: "My agent opened a Jira ticket
  against me — 'human changes requirements mid-sprint' — and assigned it to
  me, priority high." Tighter, but the em-dash aside slows the sentence and
  the punch still lands mid-line.
- **v3** — Added a third beat so the agent starts managing me: "...marked it
  high priority, and asked me for an ETA." The inversion deepens — the agent
  is no longer just filing paperwork, it is chasing me.
- **v4** — "and asks for an ETA every morning." The nagging becomes a daily
  routine; the punchline now lands at the very end and keeps happening.
  Switched to present tense "asks" so the humiliation is ongoing, not past.
- **v5** — Tried "and now it pings me for an ETA every morning." "Pings" is
  a more agent-like verb, but "now" adds a word without adding meaning.
  Kept "asks" — plainer, and the joke is already doing the work.
- **v6** — Tried dropping "marked it high priority" to save length. The
  ticket felt less bureaucratic and the process detail vanished. Reverted —
  the priority flag is part of the joke (my own agent triages me as urgent).
- **v7** — Tried a different ticket text: "Human interrupts the build with
  new ideas." Weaker than "changes requirements mid-sprint" — less universal,
  less clearly my fault, and "interrupts the build" is closer to stock
  agent-complaint territory. Reverted.
- **v8 (WINNER)** — "My agent opened a Jira ticket against me: 'Human
  changes requirements mid-sprint.' It assigned it to me, marked it high
  priority, and asks for an ETA every morning." (164 chars)
  Why it won: named artifact (Jira ticket) + the process inverted twice
  (ticket filed against the human, then assigned to the human) + punchline at
  the end (the agent chases ME for an ETA every morning). Every word earns
  its place, 164 chars inside the proven 100–170 joke band, and it is a
  different inversion from the past winners (no flaky-marking, no `ls`
  permission, no CODEOWNER, no git blame).
